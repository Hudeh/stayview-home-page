# StayView YouTube video series

Training + sales playlist: **onboard a new hotel** → **configure the property** → **run every department**.

Use this as the filming bible. Record in order so each video assumes the previous one. Publish as one playlist: **StayView PMS — Full Hotel Training**.

**Suggested format:** 6–12 minutes per video (night audit, POS, and inventory can go 12–18). End every video with: *what we did*, *what’s next*, and a link to the playlist / demo (`stayview.com.ng/demo`).

**Apps to show on camera**

| App | URL (cloud) | Who |
|-----|-------------|-----|
| Backoffice | `config.stayview.com.ng` | Owner / vendor |
| StayView PMS | `{alias}.app.stayview.com.ng` | Front desk, HK, accounts, GM |
| Outlet POS | `{alias}.outlet.stayview.com.ng` or **Outlet desktop** | Waiters / cashiers |
| Booking engine | hotel website widget | Guests (Platinum) |

## Recording tips

1. Use one demo property (`1000` or similar) and reset data between seasons if needed.  
2. Film **Hotel Setup (04)** before any FO/POS video.  
3. Film **POS desktop (17)** on the real Electron app so printers are visible.  
4. Thumbnail text: short benefit (“Check in in 60 seconds”, “Night audit in 5 minutes”).  
5. Description template:

```text
StayView PMS — [video topic]

In this video:
- …
- …

Full playlist: [link]
Try StayView: https://stayview.com.ng/demo
PMS login: https://app.stayview.com.ng
Outlet POS: https://outlet.stayview.com.ng
Backoffice: https://config.stayview.com.ng
```

6. End screens: next video in the numbered list (not random uploads).
